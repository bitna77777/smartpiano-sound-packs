# Piano packs v1.0.0

First optional Smart Piano sound-pack release.

## Splendid Mobile Alternate

- 88 true-stereo OGG samples
- 22 recorded pitches × 4 recorded velocity layers
- 8,091,222 installed sample bytes
- Public-domain Splendid Grand Piano source pinned to commit
  `1c595d827b7fd7f0be3134aaed0f90b3662a09cf`
- Signed catalog and per-file SHA-256 verification

The bundled Salamander Mobile 8-layer Grand Piano remains the app's default,
works offline, and is never removed by this optional download.
