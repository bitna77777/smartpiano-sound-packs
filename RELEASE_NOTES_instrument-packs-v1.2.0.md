# Smart Piano instrument expansions v1.2.0

This release publishes all 21 currently audited optional instrument expansions.

- Yamaha upright, Steinway grand, and FM electric piano
- Violin, viola, cello, contrabass, and harp
- Trumpet, French horn, trombone, and tuba
- Flute, alto saxophone, clarinet, oboe, and bassoon
- Accordion, marimba, vibraphone, and nylon guitar

Every pack is immutable, includes source/license metadata and per-sample SHA-256 checksums,
and is referenced by the detached ECDSA-signed production catalog.
